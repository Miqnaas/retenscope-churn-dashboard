# RetenScope — Simple Student Frontend

University graduation project: **Customer Churn Prediction and Retention Management**.

This version was rebuilt to make the frontend easy for a beginner to read, explain, and extend. It follows the colors and page layout of our Figma RetenScope design.

## How to run

1. Open **`index.html`** in Chrome or Edge. There is no npm, installation or build step.
2. Click the left sidebar links to change pages.
3. All pages are real `.html` documents, not generated by JavaScript.
4. For GitHub Pages, push the files to `main`; the included workflow deploys them.

## Simple folder structure

```text
RetenScope_Simple_Frontend/
├── index.html           Dashboard
├── customers.html       Customer table + filters
├── customer.html        Example customer profile
├── explain.html         Explainability preview
├── import.html          File selection preview
├── campaigns.html       Campaign board
├── new-campaign.html    Create campaign draft
├── outcomes.html        Outcome notes
├── reports.html         ML baseline results
├── settings.html        Current/future architecture
├── style.css            ALL page styling
├── script.js            Small optional interactions
├── assets/              Logo SVGs
└── .github/workflows/    GitHub Pages deployment
```

## What is working?

- HTML links navigate between pages.
- Search and risk filtering work on the Customers table.
- Threshold slider changes the classification example.
- CSV file control displays filename and size (does not upload data).
- Campaign form saves **one draft** in the browser using `localStorage`.
- Outcome form adds a row until you refresh the page.
- Layout works on desktop and mobile.

## What is NOT connected?

This is **only a frontend demonstration**. There is **no real authentication, ML inference, SHAP computation, database or messaging system**. Individual customer scores and campaign rows are mock examples. The reported dataset/model summary numbers are taken from the team's phase report. The dataset is a snapshot and does not establish a 30/60-day churn forecast.
